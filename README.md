# 홍보자동화

매장 사진을 인스타그램용으로 자동 변환하고, 로고를 넣고, 채널별 홍보 문구까지 한 번에 만들어주는 도구입니다.

브릿지 커피 매장 운영을 위해 만들었습니다. 개발을 모르는 사람도 쓸 수 있도록 바탕화면 아이콘을 더블클릭하는 방식으로 실행합니다.

## 하는 일

1. **사진 변환**: `사진` 폴더의 jpg, png 사진을 1080 x 1080 정사각형으로 바꿉니다. 가운데 기준으로 잘라서 사진이 찌그러지지 않습니다. 원본은 건드리지 않습니다.
2. **로고 넣기**: 오른쪽 아래에 로고를 넣습니다. 로고 크기는 사진 가로의 15%이고, 가장자리에서 40픽셀 안쪽에 놓습니다. 흰색 네모 판 위에 올려서 어떤 배경에서도 눈에 띕니다. 로고 파일이 없으면 이 단계는 건너뜁니다.
3. **홍보 문구 만들기**: `자료/가게 정보.txt`를 읽어서 감성형 / 정보형 / 이벤트형 3가지 버전을 채널별로 만듭니다.
   - 인스타그램: 해시태그 10개 포함
   - 네이버 블로그: 해시태그 없이 길게
   - 카카오톡 단골 공지: 3줄 이내

문구는 `자료/내 말투.txt`의 사장님 글을 분석한 말투(이모지 없음, 짧은 "~습니다" 문장)로 만들어집니다.

## 사용법

바탕화면에 만든 `홍보물만들기.bat`를 더블클릭하면 됩니다.

또는 이 폴더에서 아래 명령어를 실행합니다.

```
python 사진변환.py
```

자세한 순서는 [사용설명서.txt](사용설명서.txt)를 참고하세요.

## 폴더 구조

```
홍보자동화/
├── 사진변환.py        # 메인 프로그램
├── 사용설명서.txt      # 매주 쓰는 방법
├── CLAUDE.md          # Claude와 작업할 때의 규칙
├── 사진/              # 변환할 사진을 넣는 곳
├── 자료/              # 가게 정보.txt, 내 말투.txt, 로고.png
└── 완성/              # 변환된 사진과 홍보문구.txt가 저장되는 곳
```

## 준비물

- Python 3
- Pillow (`pip install pillow`)

## 매주 할 일

1. 사진을 `사진` 폴더에 넣습니다.
2. `자료/가게 정보.txt`의 "이번 주 홍보할 것"만 이번 주 소식으로 바꿉니다.
3. 실행합니다.
4. `완성` 폴더에서 사진과 `홍보문구.txt`를 확인합니다.
